## Rules

- Public repository. Team of up to 4 (solo allowed).
- The demo must show **only** features built during the hackathon. Startups may build on existing products but must clearly mark what's new. This repo is a fresh build, so that's simple.
- Disqualified if the project breaks legal, ethical or platform policies, or uses code, data or assets we have no rights to.
- Anti-projects: AI medical advice; **basic RAG**; simple image analyzers; simple "AI for education" chatbots; job screeners; nutrition coaches; personality analyzers; sports coaches; **anything political or involving war**.

## Submission (via the Cerebral Valley platform)

- Public GitHub repo, **3-minute demo video** (one of the main things judges look at), live product link, list of everyone who worked on it.
- README must include a "Built during the hackathon" section and a "Pre-existing assets" section.

## Judging

1. Pass/fail: fits the theme and genuinely uses Meta Model API and/or Meta open-weight models.
2. Scored 0–10: **Impact 30%**, **Use of Meta AI tooling 25%** (creative, beyond a basic integration), **Technical depth 20%**, **Demo 25%** (working, impressive, holds up live).
3. Top 5 per track: final judges watch the videos live.
