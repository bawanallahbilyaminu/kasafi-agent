# Kasafi

Kasafi is a WhatsApp assistant, in Hausa and English, that answers questions about public documents from Sokoto
State, Nigeria: budgets, budget performance reports, policies, development plans and reports from development
partners. It cites the document and page for every fact. It is run by **Halal Numeriq Limited**, Sokoto.
